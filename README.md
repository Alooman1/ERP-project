# Full ERP System

A modular **Enterprise Resource Planning (ERP)** system developed in **Java** with a **Swing-based GUI** and **MySQL-backed persistent storage**.  
The project emphasizes **clean software architecture**, **testability**, and **real-world software engineering practices**.

---

## 1. Features

- Manage and persist **100+ records** across multiple ERP entities
- Interactive and responsive **GUI-based workflows**
- Modular and extensible codebase
- Reliable database-backed persistence using MySQL
- Automated testing for correctness and stability

---

## 2. Tech Stack

- **Programming Language:** Java  
- **GUI Framework:** Java Swing  
- **Database:** MySQL  
- **Testing Framework:** JUnit  
- **Tools:** Git, VS Code / IntelliJ IDEA  

---

## 3. System Design & Architecture

- **Object-Oriented Design (OOP):**  
  Used encapsulation, inheritance, and polymorphism to build reusable and maintainable components.

- **Modular Architecture:**  
  Core functionalities are organized into independent modules, enabling easy feature extension and maintenance.

- **Separation of Concerns:**  
  Clear distinction between:
  - User Interface Layer  
  - Business Logic Layer  
  - Database Access Layer  

- **Scalability Considerations:**  
  Designed to handle increasing data volume and additional ERP modules with minimal refactoring.
